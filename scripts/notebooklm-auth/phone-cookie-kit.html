NotebookLM phone auth kit

Turns what your phone can export into the exact secret value the automation needs. Runs entirely offline — a Content-Security-Policy on this page blocks all network access, so nothing you paste can be sent anywhere.

Fast path — works for a few weeks

Exports your live Google session. Quickest way to get testing, but Google rotates these cookies, so expect to redo it every 2–4 weeks.

  1. Install a browser that supports extensions, plus a cookie‑export extension (see the runbook for which ones work on your phone).
  2. In that browser, sign in at notebooklm.google.com and let the page fully load.
  3. Export cookies for this site, then repeat for google.com and accounts.google.com.
  4. Paste each export below — one at a time is fine, they accumulate.

Durable path — do this once

Captures a single‑use provisioning token. The server exchanges it for a long‑lived credential that re‑mints cookies by itself, so this survives cookie expiry with no further phone steps.

  1. In the same extension-capable browser, open https://accounts.google.com/EmbeddedSetup
  2. Sign in and accept the prompt. The page then hangs on a spinner — that is expected, and the token is already set.
  3. With the cookie extension, copy the value of the oauth_token cookie on accounts.google.com. It starts with oauth2_4/.
Use a throwaway Google account. The credential minted from this token grants full access to the account and keeps working after a password change, until you revoke it. Do not use your primary account.

This page never transmits data. Verify it yourself: it loads no external scripts, styles, or images, and its Content-Security-Policy is default-src 'none', which makes network access impossible rather than merely unused.
